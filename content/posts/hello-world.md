This is the first post on my blog. Delete or rewrite it; it exists to show what a post looks like.

## Why write in public

Writing forces me to understand things properly, and a searchable record of what I learned saves future-me (and maybe someone else) a lot of time.

## What I'll write about

- Projects I'm building and the decisions behind them
- Short notes on tools, bugs and fixes
- Things I got wrong, so you don't have to

## What a post can contain

Standard markdown works: **bold**, *italic*, `inline code`, [links](https://github.com), lists and quotes.

> Quotes render with an accent rule on the left.

```ts
// fenced code blocks are supported
export const greet = (name: string) => `Hello, ${name}!`;
```

| Format   | Supported |
| -------- | --------- |
| Tables   | Yes       |
| Diagrams | Inline SVG |
| Images   | Put files in `public/` |
